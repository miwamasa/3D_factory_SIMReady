# 工場 3D ビュー

Motor Factory Labを起動し、左側の **工場 3D** を選びます。Three.jsがBlenderから書き出したGLBを読み込み、S01〜S06の設備、仕掛品、状態ランプを同じシミュレータの状態に合わせて表示します。S01〜S06のタグを押すと、その工程のキュー、シリアル番号、処理進捗を確認できます。

```sh
python3 server.py --demo
```

既存サーバーを起動中の場合は、停止してこの版を起動すると3D用のファイル配信と新しい指標が利用できます。ブラウザはWebGLに対応している必要があります。[3Dビューを開く](http://127.0.0.1:8765/#factory3d)

| 表示 | 定義 |
|---|---|
| 生産速度 | 直近約5仮想分のEOL検査完了数を台/時に換算。良品・不良品の両方を数えます。起動直後は取得済みの期間で計算します。 |
| WIP | 全工程にいる加工中・待機中の台数。 |
| 平均リードタイム | 最近20台の検査記録のうち、投入時刻を持つ台の「S01投入からS06検査完了」までの平均。待ち・ライン停止中の仮想時間を含みます。旧データの投入時刻がない台は平均から除きます。 |
| 仮想時間・倍率 | シミュレータの時計と、実時間1秒で進める仮想秒数。生産速度は検査実績から別に計算します。 |

ドラッグで回転、スクロールで拡大・縮小、右ドラッグで移動します。**斜め** と **上面** は全体、**接写** は選択中の設備を映します。通常表示では仕掛品がコンベヤーから治具へ移り、加工に合わせて部品が加わります。加工進捗はPython側で計算し、ブラウザで取得した値の間を補間します。

## 組立動作を見る

1. **工場 3D** で、画面下の **S04 ハウジング組付** を選びます。
2. **工程デモ** を押します。選択工程に接写し、アームが外装を持ち上げ、軸に沿って差し込む動作を繰り返します。
3. 工程を選び直すと、その動作に切り替わります。もう一度 **工程デモ** を押すと通常表示に戻ります。

工程デモはブラウザ内のサンプルを約8秒で一周させる表示です。時計停止中や仕掛品ゼロのときも、人のキーを入力せずに使えます。仮想時計・製造指図・仕掛品・KPIは引き続きシミュレータの実測値を表示します。

| 工程 | 3Dで見える動作 |
|---|---|
| S01 部材供給 | スライド式の供給ヘッドが治具の上へ移動し、ステータを載せる |
| S02 ステータ巻線 | 巻線ヘッドが回転し、ステータの端に銅線が増える |
| S03 回転子・軸受 | 圧入機が前進し、軸受と回転子が中心に収まる |
| S04 ハウジング組付 | 関節アームが放熱フィン付きの外装を運び、軸方向に組み付ける |
| S05 ボルト締付 | 締付工具が降下・回転し、フランジにボルトが加わる |
| S06 EOL検査 | カップリングと軸が回転し、試験器に測定波形のイメージを表示する |

設備の動作は工程を説明するための簡易アニメーションです。圧入力や締付トルク、干渉などの物理計算は省略しています。

## 時間ジャンプを試す

1. `python3 credentials.py supervisor` の出力を、右上の **人のキーで接続** に入力します。
2. **工場 3D** の時間ジャンプ欄で **時計を停止** を押します。自動進行を止めると、手動操作だけの時間差を確認できます。
3. **5分** を選んで **時間を進める** を押します。シミュレータが300秒分を計算し、結果の仕掛品・指標・設備状態を表示します。
4. 軸受過熱を試す場合は「ライン監視」で異常を適用し、「工場 3D」のS03を選びます。赤いランプと「異常停止」を確認できます。

時間ジャンプは現場責任者の資格情報で `POST /api/step` を呼びます。仮想時計とライン稼働状態は別に管理されます。時計を停止した状態でも、稼働中のラインは時間ジャンプの間に加工します。

## Blenderで編集する

`models/motor_factory_line.blend` をBlenderで開きます。工程はS01〜S06のコレクションに分かれ、`NV_Conveyor_*` と `NV_MaterialCrate_*` がSimReady由来のモデルです。`MOTOR_TEMPLATE` 配下にステータ、巻線、回転子、外装、ボルトがあります。工具やアーム関節は工程ノード配下のピボットを中心に動きます。アニメーションはThree.js側で組み立てます。工程・ランプ・部品・工具のノード名、ピボットの親子関係、工程のカスタムプロパティを保ってGLBを書き出してください。

元データから作り直す場合は、curlとBlenderを使って同梱スクリプトを実行します。`simready_source` は取得したUSDを保存する作業フォルダです。

```sh
python3 tools/fetch_simready.py simready_source
blender --background --factory-startup --python-exit-code 1 \
  --python tools/build_factory3d.py -- --assets-dir simready_source
```

NVIDIAモデルの改変内容とライセンス、Three.jsの配布元を記載しています。[モデルのクレジット](../models/CREDITS.md)
